# Delivery roadmap

**Phase 1 — scaffold (included):** Public responsive hotel site, illustrative rooms, inquiry form, domain use case, Prisma adapter, staff dashboard and docs.

**Phase 2 — integration verification:** Install dependencies, run typecheck/lint/build, PostgreSQL migrations, automated domain/API tests, mobile accessibility checks.

**Phase 3 — portfolio-ready deployment:** Replace placeholder visual art with appropriately licensed hotel images, deploy a no-real-PII public demo, seed fictional sample inquiries, add screenshots and a project case study. Public demo must not expose a shared staff token.

**Phase 4 — client-ready security:** Managed staff authentication, role permissions, anti-abuse controls, notifications, audit log, backups, monitoring, data policy, CI/CD and deployment hardening.

**Phase 5 — optional enhancements:** Dynamic room catalog, multilingual content, availability calendar, integrations. Real booking confirmation/payment is a separate product scope.
